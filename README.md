# М&T 1.5

Компактная компиляция односимвольной замены, безопасная оптимизация графа и начало с S₁ на символе σ. Подробности и результаты проверок: `docs/OPTIMIZATION.md`.

## Как пользоваться

1. Напишите правила Маркова слева. Допустимы `0 ->. 1` и `0 →. 1`. Быстрые кнопки над редактором вставляют обычную стрелку, заключительную стрелку и новую строку в позицию курсора. «ε — пусто» очищает выделенный фрагмент: пустая часть правила записывается отсутствием текста или отдельной λ. σ и λ зарезервированы; ε сама по себе является обычным символом.
2. Справа автоматически появится эквивалентная программа Тьюринга. Входное слово для самой компиляции не нужно.
3. Введите слово в поле слева; алфавит задаётся под панелью. Смена слова не перестраивает таблицу машины.
4. В каждой панели отдельно выберите «Выполнить сразу» или «Пошагово».

«Выполнить сразу» выполняет соответствующую программу с начала на текущем входном слове до завершения или лимита. Работа идёт в isolate и не блокирует интерфейс.

«Пошагово» подготавливает соответствующую модель с начала. Затем «Следующая подстановка» выполняет ровно одну подстановку Маркова, а «Следующий переход» — ровно одну команду Тьюринга. Слева видна цепочка слов и номер применённого правила; справа — лента, выделенная ячейка, указатель головки, текущее состояние и следующая команда. Счётчики двух моделей не обязаны совпадать: одна подстановка разворачивается в много команд.

Кнопка со стрелкой сброса заново готовит только свою модель. Правка исходника, алфавита или входного слова сбрасывает старое выполнение. Копирование над панелью Тьюринга забирает всю программу без обрезания. Меню ⋮ позволяет сохранить текст машины, JSON машины и проекта. Солнце/луна меняет чёрно-белую тему. На телефоне панели переключаются вкладками, длинное содержимое прокручивается.

## Запись машины

На экране состояния набраны большой S с настоящим нижним индексом. Текстовый экспорт: `S_2 0 -> 1 R S_3`.

| Знак | Значение |
|---|---|
| σ | Единственный маркер начала слова |
| λ | Пустая ячейка ленты |
| Справа от слова | Только пустые ячейки λ, без отдельной границы |
| Символ в рамке / ⟦…⟧ в экспорте | Временная опора для сдвига; перед завершением отметка снимается |
| R, L, — | Вправо, влево, без сдвига |
| STOP | Отдельное состояние остановки |

Остановка определяется конечным состоянием, а — означает отсутствие сдвига. Под таблицей есть кнопка с пояснениями. Состояния и рамки — реальные технические элементы сгенерированной машины. Пользовательские символы и технические знаки имеют разные численные ID в JSON.

## Заключительное удаление

Для входа `01010`:

- `0 →.` даёт `01010 → 1010` и сразу останавливается после одной подстановки.
- `0 →` даёт `01010 → 1010 → 110 → 11`: обычное правило применяется повторно.

Сам список команд справа не является процессом выполнения. О ходе исполнения говорят состояние, лента и статус под таблицей. После остановки кнопка следующего шага недоступна; это исключает лишние подстановки заключительного правила.

## Обновление и запуск

Закройте старое приложение. Распакуйте архив в новую папку и откройте PowerShell **рядом с pubspec.yaml**, не в папке Flutter SDK:

```powershell
flutter pub get
flutter run -d windows
```

Нужен Flutter 3.50.1 / Dart 3.14. Повторная установка Visual Studio / Android Studio не нужна, если они уже настроены. Локальные проекты совместимы с предыдущими версиями.

## Сборка

| Платформа | Команда | Требуемая среда |
|---|---|---|
| Windows | `flutter build windows --release` | Windows, Visual Studio C++ |
| Android | `flutter build apk --release` | Android SDK |
| macOS | `flutter build macos --release` | macOS, Xcode |
| iOS | `flutter build ios --release --no-codesign` | macOS, Xcode; для установки нужна подпись |

Windows: передавайте всю папку `build/windows/x64/runner/Release`, включая DLL и data, а не только EXE. Есть `scripts/Build-Windows.ps1`. Android APK: `build/app/outputs/flutter-apk/app-release.apk`, текущая конфигурация подписывает development key. Для постоянного распространения нужен свой ключ. macOS: `build/macos/Build/Products/Release/М&T.app`. iOS: открыть `ios/Runner.xcworkspace`, настроить Signing & Capabilities → Team и Bundle Identifier; неподписанный bundle сам по себе на iPhone не устанавливается.

Нативные пакеты версии 1.5 в этой Linux-среде не собирались. Ранее пользователь запустил приложение на Windows. Физические устройства и системные диалоги ещё требуют проверки. Все вычисления после установки работают офлайн; при первой сборке загружаются зависимости.

## Проверка и пределы

`flutter analyze`, `flutter test`, `dart run tool/check.dart`. Документация настоящей компиляции — `ARCHITECTURE.md`. Симулятор Тьюринга выполняет исключительно таблицу δ.

Ограничения: ≤100 правил, ≤128 символов в части правила, ≤40 000 состояний и ≤500 000 переходов. По умолчанию исполнение ограничено 1 000 подстановками, 200 000 переходами, 5 секундами активного вычисления и 300 сохраняемыми шагами истории. Достигнутый лимит не считается остановкой алгоритма или доказательством эквивалентности. История явно сообщает, если показан только хвост вычисления. Изменение исходника отбрасывает устаревшие фоновые результаты. Запущенное вычисление доходит до своего технического лимита, его устаревший результат не публикуется.

Текст/JSON на телефоне можно копировать; прямое системное сохранение из диалога экспорта поддерживается на компьютере. PDF-экспорт пока не добавлен.
