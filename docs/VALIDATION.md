# М&T 1.5 — проверка

Flutter 3.50.1 / Dart 3.14, Linux x64. Все 69 тестов пройдены; flutter analyze — без замечаний. Полный вывод сохранён в flutter-test.txt и flutter-analyze.txt.

Подробный отчёт по оптимизации: OPTIMIZATION.md. Реальная таблица и протокол запуска: optimized-execution.txt; экспорт самостоятельной машины: optimized-machine.json. tool/inspect_optimized.dart воспроизводит оба результата.

Сохранены дифференциальные проверки универсального компилятора, включая более 7 000 сравнений с независимым интерпретатором Маркова, рост, удаление, вставку, пустое слово, пустой образец, терминальные подстановки, приоритеты и пересечения. Дополнительно проверены специальная стратегия, недостижимые и эквивалентные состояния и 600 сравнений полной ленты/головки до и после оптимизации графа.

Лента использует σ и λ без правого ограничителя. JSON машины версии 3 содержит канонические S_1/STOP, internalId и initialHead=0. Восстановление и самостоятельное исполнение экспортированной таблицы проходят. Проекты с исходниками сохраняют формат; λ/σ теперь зарезервированы для пустоты и начала ленты.

Пошаговое и полное исполнение, UI, быстрые стрелки, светлая/тёмная тема и пять размеров экрана проверены. desktop.png — рендер компактной машины из действующего Flutter UI после шести переходов на входе 1111. Нативные пакеты Windows/Android/macOS/iOS в этой среде не собирались.
