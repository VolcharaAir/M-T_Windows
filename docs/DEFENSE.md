# Демонстрация М&T

1. Написать `1 -> 0`, задать алфавит `01` и вход `1111`. Справа показать четыре перехода, S₁ и STOP. Пройти шесть шагов Тьюринга до `0000`.
2. Объяснить, что это программа для любого слова над заданным алфавитом, а не результат обработки одного входа.
3. Скопировать программу: экспортируются все переходы, старт и остановки.
4. При необходимости открыть «Проверить на слове» и сравнить результаты для `1111` (обе программы выдадут `0000`).
5. Взять пример с приоритетами: `00 -> 1`, `11 ->. 0`. Для `1100` сначала применяется первое правило, получается `111`, затем заключительное — `01`.
6. Объяснить, почему у сложного примера справа больше строк: машине нужны поиск подстроки, перенос символов, сдвиги и возврат к первому правилу. Все действия представлены обычными δ.
7. Аргумент корректности: одинаковый выбор правила и левейшего вхождения; точное удаление и вставка сохраняют остальное слово; после замены восстанавливается инвариант ленты. Подробности в ARCHITECTURE.md.

Для одиночной обычной замены разных символов используется один проход. Количество исходного символа убывает и не восстанавливается; результат совпадает с повторными заменами Маркова. Для нескольких правил такая оптимизация не применяется: их приоритет и повторный запуск могут менять результат и завершение. Оптимизатор графа отдельно удаляет недостижимые состояния, объединяет доказанно эквивалентные и перенумеровывает BFS.
